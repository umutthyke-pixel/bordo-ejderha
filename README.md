# 🐉 Bordo Ejderha — 3D Uçuş Simülatörü

Three.js ile geliştirilmiş, 90'lar & 2000'ler Türkçe pop/rock klasikleri eşliğinde sinematik ejderha sürme oyunu.

## 🚀 Canlı Oyna
👉 **[https://umutthyke-pixel.github.io/bordo-ejderha/](https://umutthyke-pixel.github.io/bordo-ejderha/)**

## 🎮 Kontroller
- **🖱️ Fare:** Ejderhayı yönlendir (Yukarı/Aşağı/Sağa/Sola bakış)
- **W / S:** Hız artır / Yavaşla
- **A / D:** Sağa / Sola yatış
- **Q / E:** 🔄 Fıçı Taklası (Kule oklarından kusursuz sıyrılma + hız)
- **F:** 💥 Mega Alev Topu (Uzun menzilli kule imha güllesi)
- **SPACE:** 🔥 Ejderha alevi püskürt
- **SHIFT:** ⚡ Turbo kükreme
- **V:** 🎥 1. Şahıs Kokpit / 3. Şahıs Takip Kamerası değiştir
- **T:** 🌅 Gün Doğumu / Gün Batımı gökyüzü modu
- **G:** ⛈️ Sağanak yağmurlu ve şimşekli Fırtına modu
- **M:** 📜 Şarkı listesini aç / kapat
- **N / P:** ⏭ Sonraki / Önceki şarkı

## 🎵 Müzikler
76 adet unutulmaz Türkçe klasik parça, özel ses sentezleyicileri, dinamik rüzgar ve kükreme efektleri.

## 🛠️ Teknolojiler
- HTML5, CSS3 Glassmorphism UI
- Three.js (WebGL 3D Render)
- Web Audio API (Sentetik rüzgar, alev ve kükreme efektleri)
- GLTF/GLB 3D Ejderha ve Kule Modelleri
